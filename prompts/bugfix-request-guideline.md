# Bugfix 요청 지침 (시스템용)

아래 형식으로 요청하면, 분석 품질과 재현성이 올라갑니다.

## 목표
현재 프로젝트를 코드리뷰해서 치명도 순(Critical/High/Medium/Low)으로 이슈를 정리하라.

## 출력 형식
각 이슈마다 반드시 포함:
1. 파일 경로
2. 문제 원인
3. 최소 수정안
4. 검증 명령

## 실행 요구사항
- 즉시 수정 가능한 항목 1개는 실제로 수정한다.
- 변경 파일 목록과 diff 요약을 제시한다.
- 마지막에 남은 리스크와 후속 테스트 계획을 짧게 정리한다.

## 실행 범위
- 현재 작업 디렉터리만 대상으로 분석한다.
- 추정이 필요한 경우 "가정"으로 명시한다.

## 예시 한 줄 요청
현재 프로젝트를 코드리뷰해서 치명도 순으로 이슈를 정리해줘. 각 이슈마다 파일 경로, 문제 원인, 최소 수정안, 검증 명령을 포함하고 즉시 고칠 수 있는 항목 1개는 직접 수정까지 진행해줘.
